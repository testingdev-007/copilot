Transform: one source, many audiences

5 min

Step one up from summarising: take the same information and reshape it for the people who need it. The worked example is a messy staff survey about a new expenses system. Download it, open it in Excel (or paste it into Copilot Chat) and follow the three prompts.

The data (first 10 rows, deliberately messy)

Spot the problems: mixed date formats, a blank comment, a score written "4/5", a duplicate. This is real-world data, so it's a fair test.

Three prompts, in order

Prompt A · Clean 
Clean this survey data. Make all dates DD/MM/YYYY, turn scores into whole numbers 1 to 5, remove exact duplicate rows and flag any blank comments. Tell me what you changed.
Prompt B · Find themes 
Add a Theme column. Group each comment into one of 5 to 6 themes. Then make a table of theme counts with average score, sorted by most mentioned.
Prompt C · Three audiences 
Using these themes, write three versions: (1) a 3-sentence note for the executive team, (2) a bulleted action list for the project team, (3) a friendly "You said, we're doing" message for all staff. No jargon.

What good looks like

Your themes will differ slightly, and that's fine. Roughly, Copilot should find something like this:

The shift: you did not write any of those three messages. You described the audience and the shape. That habit, describing the audience first, is what every later step builds on.

Process: an agent that answers so you don't have to
5 min

  
A tool waits to be opened. A process runs on its own: it answers the same ten questions at 2am, routes the request, drafts the reply. In Copilot this is an agent: instructions, some knowledge, and clear limits. Design one below.

Where does a process like this help?

    

      
Trigger
Someone asks the same question again: "How do I claim mileage?"

      
Action
The agent finds the answer in your approved document and replies in your tone.

      
Hand-off
If it isn't in the document, it passes the question to a person, without guessing.

    

  


  
Try it. Open the agent builder available to you (in Microsoft 365 Copilot or Copilot Studio, depending on your licence). Paste the instructions, upload the FAQ file as knowledge, and ask it three questions: one it should answer, one it shouldn't, and one that's tricky. The "shouldn't" test matters most.
